# 0009. Модель распространения: бесплатно, ради репутации, права у автора

**Контекст.** Тренажёр готов локально, сюжетов три. Держать открытый стенд на сотни и тысячи пользователей своими силами автор не хочет: хотя по расчёту дорого не железо (1000 сеансов в месяц — в среднем 1–2 стенда одновременно, пик гасит очередь), а эксплуатация и ответственность за чужой код на открытом сервере (ADR 0002). Продажа даёт мало: по открытым данным (поиск 09.11, `state.md`) автор курса в школе получает порядка 50–80 тыс. ₽ в месяц на время разработки с передачей прав, а лицензия платформы за место у зарубежных аналогов — от $6, то есть сотни рублей за студента. Деньги приносят обязательства: сроки, сопровождение, доступность. Доказательств спроса (сколько прошли, отзывы) пока нет, поэтому любая сделка сейчас — по нижней планке. Автор преподаёт Go в Хекслете и делает для него ролики; у Хекслета нет практики по инцидентам, дежурствам и observability, а принцип «практика в браузере без установки» совпадает с нашим. Репозиторий собирались открыть ради CI (`state.md`), и без решения о лицензии публикация размыла бы права.

**Решение.**
- **Цель — репутация, а не доход.** Тренажёр бесплатный для пользователей.
- **Целевой путь — Хекслет как партнёр и хозяин стендов:** бесплатный тренажёр под его маркой и с именем автора, сервер стендов за счёт Хекслета. Порядок: ролик на стенде → пилот на своей Go-группе → разговор с тем, кто решает про продукт.
- **Права остаются у автора.** Хекслету — неисключительная лицензия по отдельному договору; эксклюзив возможен только на сюжеты, сделанные под его курс, на каркас — нет.
- **Лицензии репозитория:** каркас (`platform/`, `web/`, `scripts/`, документы) — Apache-2.0; сюжеты (`scenarios/<id>/`: код сервиса, поломки, проверки, подсказки, разборы) — PolyForm Noncommercial 1.0.0. Коммерческое использование сюжетов — только по договору с автором. Конкретные лицензии — предложение, сверить до публикации.
- **Деньги — позже и от компаний** (онбординг дежурных, найм, self-hosted), если пилот и публикации покажут спрос. Модель тогда — лицензия за место плюс плата за сопровождение.

**Последствия.**
- Публиковать репозиторий можно только после того, как в нём лежат файлы лицензий и разметка, что под какой лицензией.
- Двойное лицензирование работает, пока все права у автора. Чужой вклад в `scenarios/` — только с соглашением о передаче прав (CLA), иначе продать сюжеты по договору нельзя.
- Пока нет договора с Хекслетом, открытого стенда нет: ролики пишутся с ноутбука, пилот — на отдельной машине по ADR 0002, её оплату обсуждаем с Хекслетом. Если Хекслет откажется, запасной путь — свой сервер с очередью и малым числом мест; решение о нём отдельное.
- Лицензия Apache у каркаса позволяет кому угодно построить на нём свой продукт, в том числе платный. Это цена репутации от открытого кода; ценность для продажи — в сюжетах, они защищены.
- Метрика успеха — не выручка, а пройденные сюжеты, отзывы, просмотры роликов и статьи. Цифру закрытого теста по-прежнему решает пользователь (`plan.md`).
