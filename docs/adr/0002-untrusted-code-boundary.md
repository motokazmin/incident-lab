# 0002. Граница для чужого кода

**Контекст.** Пользователь полигона запускает произвольный код. Единственный VPS пользователя держит торговый бот с токенами брокера. Изоляция снижает риск, но не убирает: ошибка в ней стоит денег.

**Решение.** Чужой код никогда не выполняется на машине с другими сервисами или секретами. На локальной машине выполняется только собственный код разработчика: на ней работает `bybit-tv-bot`, поэтому она не подходит под это правило. Любой другой человек, включая доверенных, и закрытый тест, и открытый запуск — только на отдельной одноразовой машине без секретов и без маршрута к другим машинам, по списку ADR 0003. Этот проект не обращается к VPS пользователя вообще.

**Последствия.** К открытому запуску нужен отдельный сервер; расход не оценён. Сервер стендов пересоздаётся из образа, поэтому взлом обходится потерей машины, а не данных. Управляющая база и секреты пользователей не живут на нём.

**Правка 05.11.** Первая редакция отправляла закрытый тест на локальную машину и противоречила сама себе. Ужесточено после ревью `sandbox-reviewer`, пользователь может пересмотреть.
