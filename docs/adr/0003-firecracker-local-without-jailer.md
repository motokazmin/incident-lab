# 0003. Firecracker, пока без jailer

**Статус:** принято для локальной разработки. Для запуска чужого кода не принято.

**Контекст.** План требует Firecracker с jailer и seccomp. Разведка подтвердила Firecracker: запуск около секунды, 382 МБ под нагрузкой, шесть стендов на 4 физических ядрах ([замеры](../reviews/2026-11-05-recon.md)). Jailer требует root, а поставки 0–2 велись без пользователя и без sudo.

**Решение.** Изоляция — Firecracker без сетевых интерфейсов и без MMDS. Единственный канал данных — vsock; поверхность атаки шире: virtio-block, entropy, serial и сам KVM. Диск образа только для чтения, диск стенда одноразовый, ограничены vCPU, память и скорость диска. Встроенный seccomp-фильтр Firecracker включён. Jailer, cgroup и отдельный непривилегированный uid пока не подключены, поэтому сервер отказывается слушать не-loopback адрес.

**Последствия.** На этой машине запускается только наш собственный код и код самого разработчика, `MaxLabs` не выше 2. Выход из виртуалки даёт права `roman`, а это фактически root: `roman` в группах `docker`, `sudo`, `lxd`, то есть доступ к контейнерам бота и его токенам. Туннели на локальный сервер запрещены: проверка loopback от них не защищает.

**Перед закрытым тестом (отдельная машина по ADR 0002):**
- jailer, cgroup CPU и памяти, свой uid на стенд; привилегированный запускатель отдельно от шлюза;
- таймауты и лимиты шлюза: соединения, файловые операции, терминалы, частота создания стендов;
- ограничители serial и entropy, ограничение потока терминала, отключённый serial вне отладки;
- хост: SMT и swap выключены, актуальный микрокод, поддерживаемые Firecracker ядра хоста и гостя;
- облако: блокировка 169.254.169.254 и исходящего трафика, сервер без роли и ключей;
- режим внешнего домена только явным конфигом, вместе с входом.

**Перед открытым запуском дополнительно:** шлюз, TLS, OAuth и cookie вне сервера стендов; голое железо; весь экран стенда на отдельном источнике без cookie сайта; стенд привязан к сессии; внешний сторож процессов; диск стенда не монтируется на хосте; отдельный раздел и `io.max`; план обновлений Firecracker; ссылки OSC 8 в xterm выключены; новое ревью `sandbox-reviewer`.

Снимать проверку loopback можно только вместе с этим списком. Разбор находок — [ревью](../reviews/2026-11-05-sandbox-review.md).
