# 0001. Стек и раскладка

**Контекст.** Один разработчик, сильная сторона — бэкенд на Go. Нужны планировщик, шлюз к песочницам и веб-интерфейс. Сценарии будут писаться чаще всего и не должны требовать правок каркаса.

**Решение.** Каркас на Go, веб на TypeScript, учебный сервис на Go. Каталоги: `platform/` — каркас, `scenarios/` — прикладной код, `web/` — интерфейс. Управляющие данные — PostgreSQL.

**Последствия.** Граница каркаса и сценариев видна сразу. Сценарии можно открыть отдельно от каркаса. Учебный сервис на Go привязывает первую аудиторию к гоферам; другие языки — отдельным решением.
