# failing-orders: разбивка залпа по путям — разбор `incident-engineer` (13.11)

Повод — проход пользователя 12.11: сортировка только в `repeatOrder` давала ровный график и провал
проверки, подсказка «база находит дедлоки» читалась как ошибка проверки. Правка: при дедлоках
в смешанном залпе проверка шлёт залп только повторов и залп только новых заказов и называет путь;
`settled` ждёт, пока база освободится (`busy` из `pg_stat_activity`). Разбор — по коду, стенд не запускался.

## Находки и что сделано

| # | находка | решение |

| 1.2 | Блокировка по составу корзины проходила: у всех корзин залпа один набор товаров. | Закрыто: своя четвёртая позиция `731+i`, `lineCount` = 4. Случай «блокировка по составу корзины». |

## Проверил и дыры не нашёл (по разбору)

Строки подсказок не пересекаются по подстроке «находит дедлоки»; заглушки путь чистым не называют;
`busy` не считает autovacuum и сам запрос; во время проверки нагрузка остановлена; сбои диагностики
откатываются к общей подсказке, а не к успеху.
