## Что понял за сессию
- Статью из Claude Docs целиком читать экспортом в markdown (результат в файле, поле `bytes_b64`), а не outline: outline обрезает текст. Пакет правок с одной неточной цитатой отклоняется целиком — цитировать по экспорту.
- Снимки для разбора быстрее всего снимать временным e2e-тестом: план команд в файле, `@alert`, `@repair <имя>`, вывод `shell()` в лог; один стенд — десятки команд за 2–3 мин против получаса в браузере. Тест удалять после.
- `psql` с выводом шире терминала или длиннее экрана открывает пейджер, и команда «не завершается». В подсказках держать вывод узким (`left(query, 80)` без лишних колонок); в своих снимках — `-P pager=off`.
- `pgrep -f <шаблон>` в `bash -c` находит сам себя; проверять виртуалки через `pgrep -x firecracker`.
- По коду мы с агентами дважды ошиблись в узком месте: «кончился пул» у `slow-orders` оказался CPU, а «CPU раннера быстрее» не объяснил зелёный прогон на раннере. Причину провала называть только с цифрами.
