# Каталог сценариев

Все инциденты, которые можно сделать. Каталог не задаёт порядок: что брать следующим, решается отдельно. Новые идеи дописываются сюда.

Требования к сценарию: поломка настоящая, нагрузка воспроизводима, починка проверяется по поведению системы, а рестарт её не проходит.

**Сложность:** 1 — путь короткий, 2 — нужно связать несколько наблюдений, 3 — неочевидная причина или несколько шагов.

**Стенд** (оценка, не проверялась):
- `готов` — хватает текущего каркаса и образа;
- `образ` — нужно добавить программу в образ сценария;
- `каркас` — нужна доработка платформы: сбой по команде, второй сервис, больше памяти, проверка ядра.

**Тип ошибки:** код, схема (данные и миграции), настройка, архитектура.

Архитектурную ошибку за час целиком не исправить, поэтому такой сценарий заканчивается небольшой правкой, которая снимает причину: разделить пулы, вынести вызов из транзакции, добавить деградацию. Разбор объясняет остальное.
