# Видеочерновик демонстрации

Немой черновик ролика: headless Chrome проходит сюжет по шагам, каждый блок пишется в свой mp4,
долгие ожидания вырезаются при записи. Озвучка и подгонка длины — при монтаже.

## Запуск

```sh
cd scripts/demo-video
npm ci                       # один раз: puppeteer-core
node record.mjs pool-exhausted   # или slow-orders
```

Нужно: `/usr/bin/google-chrome` (другой путь — переменная `CHROME`), `ffmpeg` и `ffprobe` в PATH,
собранные образы и веб (как для `scripts/run.sh`). Если сервер на http://127.0.0.1:8090 не отвечает,
скрипт сам запускает `scripts/run.sh` и гасит его в конце; уже запущенный сервер не трогает.
Стенд создаётся один, в конце закрывается. Если на машине уже работает виртуалка, скрипт откажется
стартовать: на ноутбуке стенды только по одному.

Запись идёт в реальном времени: около 10 минут на `pool-exhausted` и около 5 на `slow-orders`,
большая часть — ожидание алерта, сборки индекса и проверок.

## Что получается

В `.data/demo-video/<сюжет>/` (вне git), у каждого сюжета своя папка, чужие не трогаются:

- `blocks/NN-имя.mp4` — блок ролика (`pool-exhausted` — блоки 03–09, `slow-orders` — 10–13), 1920×1080, 30 кадров/с, без звука;
- `draft.mp4` — все блоки из `blocks/` этого сюжета подряд;
- `frames/NN-имя_SSSs.jpg` — кадр каждые 4 секунды блока и последний кадр, для проверки без просмотра;
- `parts/` — промежуточные файлы записи.

## Отладка

Починка необратима, поэтому середину сюжета отлаживают на живом стенде, не пересоздавая его:

```sh
node record.mjs pool-exhausted --blocks 3 --keep          # поднять стенд, оставить его живым
node record.mjs pool-exhausted --blocks 5,6 --lab <id> --keep
```

`--lab` открывает существующий стенд, `--keep` не закрывает его в конце, `--no-assemble` пропускает
сборку. Перезаписанный блок заменяет свой файл в `blocks/`, черновик собирается заново из всех.
Стенд закрывается через 2 минуты без запросов: между прогонами держи его открытым
(`curl -s http://127.0.0.1:8090/api/labs/<id>` раз в полминуты).

## Устройство

- `record.mjs` — запуск: сервер, браузер, блоки по порядку, сборка.
- `scenarios/<сюжет>.mjs` — шаги блоков сюжета. Новый сюжет — новый файл, механику не трогать.
- `lib/steps.mjs` — общие шаги: открыть сюжет с главной, команда в терминале, «Проверить починку».
- `lib/recorder.mjs` — запись: кадры CDP-скринкаста, ровные 30 кадров/с повтором последнего кадра,
  пауза с возвратом последних секунд (`skip` в `record.mjs`: показать начало ожидания, вырезать
  середину, вернуть момент, которого ждали).
- `lib/actor.mjs` — нарисованный курсор, плавные движения и клики, набор с человеческой скоростью,
  плавная прокрутка.
- `lib/lab.mjs` — стенд через API сервера и терминал через DOM (приглашение `lab:/srv/app#`).
- `lib/assemble.mjs` — сжатие блоков, склейка, кадры-превью.

Интерфейс крупный за счёт окна 1280×720 с `deviceScaleFactor` 1.5: страница вёрстается как на ноутбуке,
кадр получается 1920×1080.
